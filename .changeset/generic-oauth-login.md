Add generic OAuth2 and OIDC login configuration contracts, provider and registration capabilities, and import units for existing providers, OIDC registrations, and manually registered GitHub OAuth Apps.

Allow an explicit OAuth authorization server issuer independently of the stable identity authority, and configure GitHub's issuer for strict callback validation.
