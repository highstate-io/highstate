# Highstate Developer Documentation

Highstate's developer documentation preserves development and operational knowledge that cannot be inferred
from source code or configuration.

The [engineering guide](engineering/README.md) covers development practices, the
[architecture guide](architecture/README.md) covers implemented system boundaries, and the
[design guide](design/README.md) describes the current and intended shape of systems under active design.
The [authoring guide](authoring/README.md) defines this documentation's scope and writing rules.
